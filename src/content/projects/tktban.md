## What it is

A terminal-based Kanban interface for TKT, and a Herdr plugin, giving visual task
management across multiple development workspaces and AI-agent sessions.

## Why it exists

Once work is spread across several workspaces and several agent sessions, you
need to *see* it. But the obvious answer — adopt a real project management tool —
trades one problem for a heavier one.

TKTBAN is deliberately a lightweight operational layer around AI-assisted
development, not another project-management system. It lives in the terminal
because that's where the rest of the work already is.

## Current state

Active and evolving. Part of the broader TKT and Herdr ecosystem rather than a
standalone application.
