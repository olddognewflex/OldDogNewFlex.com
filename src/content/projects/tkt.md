## What it is

A ticketing CLI and AI skill system that provides a consistent work-management
and context layer across AI coding harnesses. Provider-agnostic on purpose — the
harness you're using this month shouldn't decide where your work lives.

## Why it exists

Traditional project and task management does not map particularly well onto
multi-agent software development. Tools assume one person, working in one place,
in one sequence. That assumption quietly breaks the moment several agents are
working from the same backlog and each of them needs to know what's already
decided.

TKT is what came out of designing around those practical problems — managing
tasks, context, and workflow when you're working with multiple AI development
agents rather than despite them.

## Current state

Active and evolving.

## Where to explore it

Source is on GitHub. `tktban` sits on top of it for visual work, and Qi shares
its thinking about context.
